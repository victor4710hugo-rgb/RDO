# Frontend - RDO

Aplicação Next.js (App Router, React e TypeScript) da plataforma RDO.

A documentação do projeto, a stack aprovada e o mapa de etapas estão no [README da raiz](../README.md).

## Comandos

- `npm run dev`: servidor de desenvolvimento em http://localhost:3000
- `npm run build`: build de produção
- `npm run lint`: verificação do ESLint
- `npx tsc --noEmit`: verificação de tipos
